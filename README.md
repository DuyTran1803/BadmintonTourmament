# Badminton Tournament

A single-file, offline-friendly badminton tournament manager for doubles events.

Features include:

- JSON tournament setup and validation
- Round-robin table matches and live standings
- Official one-game badminton scoring to 21, win by two, capped at 30
- Qualification and best-third-place ranking
- Single-elimination bracket with automatic byes
- Browser autosave and JSON result import/export
- Mobile-friendly courtside controls

The published app is served directly from `index.html` with no build step or external dependencies.
